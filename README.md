# 肖傲 · 个人学术主页

Personal academic homepage for Xiao Ao, hosted with GitHub Pages.

Adapted from [YoungDrifter/Profile](https://github.com/YoungDrifter/Profile), retaining its Astro components, visual system, bilingual navigation and responsive behavior. All personal information and media have been replaced with Xiao Ao's own content. The upstream snapshot did not contain a LICENSE file; no additional license is asserted for its source.

The editable source is in `site/`. Profile content is in `site/src/data/profile.ts`. From `site/`, run `pnpm install`, `pnpm check`, then `pnpm build`; copy the resulting `site/dist/` contents to the repository root for branch-based GitHub Pages publication. Fonts are served locally.
